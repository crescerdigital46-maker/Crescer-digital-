Dúvidas

Perguntas frequentes

Informações para deixar o site mais completo para seus visitantes.

Como faço minha matrícula?

Clique em “Matricular” no curso desejado. O site abre uma conversa no WhatsApp com o nome do curso para facilitar o atendimento.

Os cursos são online?

A estrutura foi preparada para cursos online com aulas em módulos. Você pode disponibilizar vídeos, materiais e exercícios depois de conectar sua plataforma de conteúdo.

Como funciona a área do aluno?

A interface já está preparada para mostrar cursos, progresso, aulas e materiais. Login, banco de dados e controle de acesso precisam ser conectados a um sistema de backend para funcionar de forma segura.

O curso de investimentos é recomendação financeira?

Não. O conteúdo deve ser apresentado como educação financeira. Decisões de investimento dependem do perfil e da situação de cada pessoa.
